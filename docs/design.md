# デザイン指針 — およげない！たいやきくん

ロゴ・立て看板・メニュー表と同じ世界観にそろえる。ただし**レジとキッチンは「速く・間違えない」が最優先**で、
装飾はお客さんが見る呼び出し表示に一番力を入れる。

## 1. ブランド要素（看板・ロゴ・メニュー表から）
- 配色：紺 × 白 × 赤。背景に波（青海波）と水しぶき
- 文字：「およげない！」は黒の筆文字、「たいやきくん」は赤の筆文字
- キャラクター：浮き輪をつけた困り顔のたい焼き
- 味の色：あんこ＝赤、カスタード＝黄、抹茶＝緑、チョコ＝茶（メニュー表の枠の色と同じ）

## 2. デザイントークン
`src/app/globals.css` に CSS変数で定義し、Tailwind の theme から参照する。

| トークン | 値 | 用途 |
|---|---|---|
| `--navy` | `#1B2A4A` | ヘッダー、主要な文字、呼び出し表示の背景 |
| `--navy-light` | `#2E4A7A` | 波模様、ホバー |
| `--paper` | `#FAF6EE` | 画面の背景（生成り） |
| `--ink` | `#1A1A1A` | 本文 |
| `--red` | `#C8322B` | 確定ボタン、呼び出し番号、強調 |
| `--anko` | `#9E3232` | あんこボタン |
| `--custard` | `#E3AE2F` | カスタードボタン（文字は `--ink`） |
| `--matcha` | `#5A8A3A` | 抹茶ボタン |
| `--choco` | `#6B4226` | チョコボタン |
| `--ok` | `#2F7D4F` | 完成・受け渡し |
| `--warn` | `#D9822B` | 10分以上待ち |

- 文字と背景のコントラストは 4.5:1 以上を守る（屋外の明るい場所で見るため）
- 状態は色だけで伝えない（「焼き待ち」「完成」などの文字も必ず出す）

## 3. 素材
- `public/brand/logo.png`：円形ロゴ（背景透過が望ましい）
- `public/brand/character.png`：キャラクター単体（あれば。なければロゴを使う）
- 青海波は画像を使わず CSS（`radial-gradient` の重ね）で描き、`.bg-seigaiha` クラスにする。濃さは控えめにして文字の邪魔をしない

## 4. フォント
- 基本は**システムの太いゴシック**（`"Noto Sans JP", "Hiragino Sans", sans-serif`、Ubuntuなら Noto Sans CJK が入っている）。数字は `font-variant-numeric: tabular-nums`
- 筆文字は任意：使う場合は OFL の和文筆文字フォント（例：Yuji Syuku）を `public/fonts/` に置いて `next/font/local` で読み込み、**見出しと呼び出し表示の「お呼び出し中」だけ**に使う。番号・金額・ボタンには使わない
- 外部CDN・Google Fonts の実行時読み込みは禁止（CLAUDE.md の制約どおり）

## 5. 画面ごとの方針
### 共通ヘッダー
紺の帯に小さいロゴ＋画面名（「レジ」「キッチン」など）。右端に接続状態（●接続中／●接続エラー）。

### レジ `/register` — 速さ優先
- 背景は生成り。装飾はヘッダーのみ
- 味ボタンは味の色で塗り、大きな文字で味名・現在の個数・残り数。押したら一瞬縮むアニメーション
- 右側の会計欄は白いカード。「金券 ◯枚」は画面で一番大きい文字
- 確定ボタンは赤、全幅
- 番号発行画面：紺背景＋青海波、中央に赤い円の中に白抜きの巨大な番号、キャラクターを添える

### キッチン `/kitchen` — 見やすさ優先
- 「焼くべき数」は味の色の大きなタイル4つ
- 注文カードは白地、左端に太い帯（焼き待ち＝紺、10分以上＝`--warn`）。味ごとに色つきのバッジ
- 完成ボタンは `--ok`

### 呼び出し表示 `/display` — ここを一番作り込む
- 全面紺＋青海波。上部にロゴを大きく
- 「お呼び出し中」の番号は白い円（浮き輪のイメージ）の中に赤い数字で大きく並べる
- 新しく完成した番号は、ぷかぷか揺れるアニメーション（数秒）＋水しぶき
- 「焼いています」の番号は下部に小さく、半透明の白
- 注文がない時間は、キャラクターと「3個セットがお得！」などの案内を表示
- `prefers-reduced-motion` のときはアニメーションを止める

### 管理 `/admin`
- 生成り背景のカード型。進捗バーは赤で、目標300個にたい焼きアイコンが泳いでいく演出（控えめに）

### トップ `/`
- 中央にロゴ、下に4画面への大きなボタン

## 6. その他

- 画面タイトル例：「レジ｜およげない！たいやきくん」
