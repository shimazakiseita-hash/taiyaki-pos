# 当日の運用手順

## 事前準備（前日まで）
### レジPC（Ubuntu）のネットワーク設定
1. ファイアウォールでポート3000を開ける：
   ```bash
   sudo ufw allow 3000/tcp
   sudo ufw status        # 3000/tcp ALLOW が出ていればOK（ufw が inactive なら何もしなくてよい）
   ```
2. テザリングにつないで、IPアドレスを確認：`hostname -I`
3. スマホから `http://<レジPCのIP>:3000` が開けることを確認
4. 当日に画面が消えたり止まったりしないよう、設定 → 電源 で**自動サスペンドと画面ブランクをオフ**にする
   - ノートPCの場合は「蓋を閉じたときにサスペンドしない」設定も確認（開けたまま使うなら不要）

### その他
- [ ] テザリング役のスマホを決める（充電しながら使う。モバイルバッテリーを用意）
- [ ] レジPC・キッチンPCの電源を確保（延長コード）
- [ ] 各端末でURLをブックマークしておく
- [ ] 本番ビルドしておく：`npm run build`
- [ ] 動作確認：`npm run start` のまま別ターミナルで `npm run load-test -- 100`（100件注文して応答時間と番号の重複を表示）
- [ ] DBを初期化：`npm run db:reset`（テストデータを消す。サーバーは止めてから実行し、あとで起動し直す）
- [ ] 予備の紙：番号札、注文メモ用紙、ペン

## 当日の開店手順
1. テザリング役のスマホでテザリングをON
2. レジPC・キッチンPC・スタッフのスマホをテザリングに接続
3. レジPCでターミナルを開き、`cd ~/dev/taiyaki-pos && npm run start`
4. 管理画面 `/admin` に表示されるURLを確認し、各端末で開く
   - レジPC → `/register`
   - キッチンPC → `/kitchen`
   - 呼び出し表示用のスマホ → `/display`
   - 責任者のスマホ → `/admin`
5. 試しに1件注文 → 完成 → 渡した まで流して、取り消しておく

## 営業中
- 1時間ごとに責任者が `/admin` からCSVをダウンロードしてバックアップ
- 材料が尽きそうな味は、メニュー表に「残りわずか」「売り切れ」を貼り、レジで口頭でも伝える（アプリに売り切れ機能はない）

## トラブル時
| 症状 | 対応 |
|---|---|
| 他の端末で画面上部に「接続エラー」 | テザリングが切れていないか確認 → 端末をつなぎ直す |
| レジPCのIPが変わった | `/admin` で新しいURLを確認し、各端末で開き直す |
| サーバーが落ちた | `npm run start` で再起動（データは残る） |
| どうしても復旧しない | **紙運用に切り替え**：番号札は最後に発行した番号の続きから手書き、注文は紙に記録し、あとでまとめて入力 |

## 閉店後
1. `/admin` で売上・金券枚数を確認し、**実際の金券の枚数と照合**
2. CSVを最終ダウンロードして共有フォルダに保存
3. `data/taiyaki.db` もUSBなどにコピーして保管
